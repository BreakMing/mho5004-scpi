# MHO5004 示波器 Skill

为 Micsig MHO5004 示波器提供可复用的 Agent 操作能力。用户完成现场接线后，可以让 Agent 调整 CH1/CH2 参数、读取测量值、保存截图与 CSV 波形，并整理成便于查看和分析的结果。无需官方上位机软件。

## 能做什么

| 能力 | 可以完成的工作 |
|---|---|
| 仪器与通道控制 | 查询设备和采集状态，控制 RUN/STOP，调整 CH1/CH2 的显示、垂直缩放、耦合等参数 |
| 测量值读取 | 获取频率、周期、幅度、峰峰值、均值、RMS、脉宽、占空比等读数，结合测量条件解释结果 |
| 屏幕截图与归档 | 保存并取回设备原始 PNG，记录来源和文件校验信息，生成可浏览历史截图的页面 |
| CSV 波形获取 | 保存并取回指定通道的 CSV，检查来源、单位、实际点数、采样间隔及文件完整性 |
| 波形分析与展示 | 分析已有 CSV，按时间范围选取局部波形，生成波形图、数据摘要及窗口数据表 |

这些能力用于辅助实验观察与问题分析。例如，检查方波的频率和幅度，查看边沿附近的过冲、振铃，或对比调整前后的截图和测量结果。分析结论依据实际取得的数据，并说明对应的采集条件和限制。

## 典型任务

- “读取 CH1 的频率、峰峰值和均值，保存当前屏幕，帮我整理结果。”
- “把当前 CH1 波形保存为 CSV，画出全图，再放大上升沿附近查看。”
- “分析这份已有 CSV，告诉我实际点数、采样间隔和时间范围，并生成波形图。”
- “对比这两次实验取得的数据，结合各自的设置说明观察到的变化。”

用户负责确认接线、实际探头倍率和实验条件；Agent 根据任务操作仪器、核验产物并保留记录。只分析已有 CSV 时不需要连接示波器。

## 会得到哪些结果

根据任务提供设备原始截图或 CSV、波形图、窗口数据表、可读摘要及操作记录。原始文件与分析结果分别保留，便于回看和核对。所有运行产物保存到工作项目或用户指定的位置，Skill 文件夹运行时保持只读。

可以查看随包历史资料的[波形图示例](assets/previews/csv-window/waveform.png)、[数据摘要示例](assets/previews/csv-window/summary.md)和[截图浏览页示例](assets/previews/screenshot-gallery/index.html)。样本元数据已脱敏，示例不代表当前仪器画面。

## 适用范围

- 目前限定 MHO5004 的 CH1/CH2，历史验证软件版本为 `1.611.171`。同源补偿方波是历史验证背景，其他信号按实际条件判断。
- 部分功能只有响应或参数回读证据，不能据此保证实际效果或测量精度；具体区分见[能力边界](references/capabilities.md)。
- CH1 CSV 有成功和失败历史，重组后的实机入口尚未实机验收，CH2 完整 CSV 导出也未实测；每次保存均需核验实际文件。
- 波形分析使用 CSV。完整文件不代表全部采集内存、无抽取或绝对精度。

运行依赖为 Python 3.11+ 和 Pillow；实机操作需要设备网络与文件访问条件。具体准备和操作方法由 [SKILL.md](SKILL.md) 及其引用资料说明。
