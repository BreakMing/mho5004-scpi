# 能力与验证边界

整理基准：2026-11-11。仅使用同一活动内真实观察及已确认限制。历史背景为 MHO5004、软件 `1.611.171`，P1→CH1、P2→CH2，两支10X、1 MΩ、同源补偿方波；不是未来任务必须使用的信号环境，也不代表当前现场状态。

首版用于 SCPI 控制、截图、测量值、CSV 及基础波形分析，模拟通道限 CH1/CH2。参考通道 R1～R4 是文件显示功能，不扩大模拟输入范围。当前任务若超出边界，说明所缺条件，不自动扩测。

## 证据的用法

- 功能已验证仅限所列条件和判据；历史通过不代替本次输出核验。
- 仅响应／回读保留供任务调用，设置会改变状态，不能一概称为只读；实际效果和精度另判。
- 精确形式被拒不代表整棵命令树不可用。条件不足、未执行和异常分别说明，不猜测通过或固件故障。
- [命令索引](command-index.md)保留历史命令形式、手册定位和必要的典型响应；它们不重新裁定历史功能标签，也不以条数充当覆盖率。完整原始响应已单独归档。部分画面判据采用已确认的历史结论摘要，不声称随包具有所有原始画面；本次任务的实际效果仍需本次证据。

## 有局部实际功能证据

| 功能 | 证据支持的范围 | 限制 |
|---|---|---|
| RUN/STOP | 操作后查询到相应状态 | 不独自证明一份新的有效采集 |
| CH1/CH2显隐、缩放 | 显隐有画面；CH1 0.5/1 V/div、CH2 1/2 V/div有幅高变化 | 不外推所有档位或独立源识别 |
| AC/DC耦合 | 两路在历史方波条件下均值改变并恢复 | 不等于阻抗/频响或精度检定 |
| 居中 | 触发平台中点、垂直/水平位置回零的数值效果 | 不代替独立画面裁定 |
| 频率计 | 两路读数及与内部测量读数的一致性 | 设备可返回 `1.00000 kHz`，不证明绝对准确度 |
| 统计计数 | RUN时更新、STOP后可查 | STOP后可能继续结算；复位后恢复累计未验证 |
| 4段采集计数 | 实际达到4段并停止 | 段内容/回放未验证；关闭后数量保留4，不能承诺回到0 |
| 特定数学实例 | CH1+CH2，以及CH1 A=2、B=1有局部效果证据 | 不扩展到任意运算或系数 |
| 截图 | 保存并FTP取回PNG；时间戳/反色有局部画面 | 取得图片不等于画面无遮挡、内容可判读 |
| CH1 CSV | 已有STOP/Local/ALLSegments0/唯一字母数字名称的完整生成、取回和绘图实例 | 同时有未生成CSV的失败；不承诺自动保存稳定成功 |
| 波形文件/REF | BIN/MWAV文件取回、活动内原MWAV加载R1～R4及显示/元数据 | 不等于逐点解码；新MWAV须单独核验，默认分析入口仍为CSV |

## 仅响应／回读及受限能力

| 类别 | 可调用的已有证据 | 保留限制 |
|---|---|---|
| 身份/状态/参数 | 探头、输入阻抗、显示、采样率、深度选择值等查询 | 不证明物理探头倍率、实际阻抗或全部点数 |
| 测量值 | 频率/周期、平台/幅度、脉宽/占空比、峰峰值/最大最小/RMS/均值 | 有效读数不等于绝对精度，异时读数不天然同次采集 |
| 反相/带宽 | 两路设置回读 | 对应反相画面和高频效果缺证据 |
| 时基/显示 | 尺度/位置、ROLL、XY/YT、ZOOM | 未全部画面核验；XY曾超时/延迟回读 |
| 采集模式 | 普通/平均/包络/峰值及次数回读 | 不证明算法效果 |
| 触发/SINGLE | 边沿、正负脉宽参数及WAIT/STOP | SINGLE缺独立的新采集证据，不能保证抓到目标事件 |
| 数学参数 | 运算符、AX+B、高级公式及FFT部分参数 | 减法/FFT实际效果暂缓；仅上表特定实例有功能结论 |
| 菜单/AUTO | 菜单、AUTO选项及一次动作响应 | 界面/优化效果不完整；AUTO会改参数 |

## 明确被拒的七个精确查询

这些形式曾返回 `Error:SCPI Command error!`，不作为正常调用路径：

1. `:SYS:SCR?`
2. `:MATH:AX+B:VPOSiton?`
3. `:MATH:ADVanced:VARiable1?`
4. `:MATH:ADVanced:VPOSiton?`
5. `:STORage:SAVE? CH1`
6. `:STORage:SAVE? CH2`
7. `:STORage:SAVE? MATH`

截图使用 `:STORage:CAPTure:STARt` 经固定入口保存及FTP取回。保存查询被拒不代表实际保存不可用。高级数学单位查询曾空返回；不将空值当0或推断全部数学不可用。统计复位后曾出现六个 `NONE`，恢复累计未验证。

## CSV与本交付的验证状态

波形和窗口使用CSV，按文件时间列筛选，单位/间隔/零点依据实际文件，不固定为360K，不重复探头倍率或偏置。完整下载不证明全部采集内存、无抽取或绝对精度，有限窗口中未发现异常不证明信号绝无异常。

随包历史样本为180000点CH1；本地解析/窗口选择有真实文件验证。CH2在通道范围内，但完整CSV导出未实机验证。保存入口的底层顺序有历史成功实例；重组后的随包截图/保存/通信路径本轮仅做本地搬移检查，未实机验收，不能继承为新入口已通过。每次真实任务核验产物、来源及末态。

配置保存/加载、CH3/CH4、协议、恢复出厂和未确认二进制解码不在首版；不使用官方上位机。暂缓或受限状态不要求使用前补齐整套测试。完整交付与本地验证记录见[交付说明](../DELIVERY.md)。
