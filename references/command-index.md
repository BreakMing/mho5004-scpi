## 典型历史响应

以下示例来自 2026-11-04～09 的 MHO5004（软件 `1.611.171`）真实响应，原接线为 CH1/CH2、两支 10X、1 MΩ、同源补偿方波。示例用于解释返回格式和兼容限制，不代表当前读数或本次执行结果；本次任务仍须保存和核验实际响应。完整来源记录和原始响应已单独归档，本 Skill 的运行与查阅不依赖该归档。

| 命令 | 历史返回示例 | 如何解释 |
|---|---|---|
| `:CHANnel1:INPutres?` | `MEGA` | 设备报告 1 MΩ 档位；不证明实际物理阻抗。 |
| `:CHANnel1:PROBe?` | `10.0` | 设备设置为 10X；物理探头倍率仍需现场确认。 |
| `:TRIGger:STATus?` | `WAIT` | 等待触发；不独自证明已完成一次新采集。 |
| `:MEASure:FREQ? CH1` | `1000.0020141601562` | 频率读数按 Hz 解释；测量打开条件见操作参考，不证明绝对精度。 |
| `:MEASure:COUNter:VALue?` | `1.00000 kHz` | 频率计返回值含单位，换算为 1000 Hz。 |
| `:SYS:SCR?` | `Error:SCPI Command error!` | 该查询形式曾被拒；截图使用固定截图入口。 |
| `:STORage:SAVE? CH1` | `Error:SCPI Command error!` | 保存查询曾被拒；不能据此判定实际保存动作不可用。 |
| `:MATH:ADVanced:UNIT?` | 空响应文件（0 字节） | 历史响应文件为 0 字节；不当作 0，也不独自判定查询成功。 |
